## IMPORTANT RULES

- Keep component names, variable names, CSS classes in English
- Keep aria-label attributes in English (accessibility standard)
- Keep placeholder emails like "you@example.com" as-is
- Translate title= attributes that are visible tooltips
- Translate toast messages (both success and error)
- Keep technical terms like "JSON", "API", "URL", "webhook" as-is
- sr-only text (screen reader) should stay in English
