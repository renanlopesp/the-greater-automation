# Quickstart: Real Onboarding + Brand DNA

## Prerequisites

- Supabase running with `stores`, `store_products`, `brand_dna`, `skills` tables
- Nuvemshop OAuth configured (client_id, client_secret in env)
- LLM API key configured (GPT-5.2 via Vercel AI SDK)
- A real Nuvemshop store with products to test

## Development Flow

### 1. Apply migrations

```bash
# Add recommended_skills, owner_name, greeting, intro to brand_dna
supabase db push
```

### 2. Test store connection

1. Open `http://localhost:3000/onboarding`
2. Click "Connect your store"
3. Click "Connect via Nuvemshop"
4. Authorize on Nuvemshop
5. Verify: callback redirects to `/onboarding/analyzing`
6. Verify: `stores` table has new record with `platform_access_token`

### 3. Test analysis pipeline

1. On `/onboarding/analyzing`, verify real progress:
   - Step 1: "Sincronizando X produtos..." → "X produtos sincronizados"
   - Step 2: "Gerando Brand DNA..." → "Brand DNA gerado"
   - Step 3: "Mapeando Y datas sazonais..." → "Y datas mapeadas"
2. Verify: `store_products` table has products
3. Verify: `brand_dna` table has generated record
4. Click "Continue" → redirects to `/onboarding/brand-dna`

### 4. Test Brand DNA page

1. Verify all 8 sections show REAL data (not Milkes mock):
   - Greeting with real owner name
   - Real niche detected from catalog
   - Real tone of voice
   - Real strengths/alerts
   - Real opportunities with dates
   - Real revenue projection
   - Recommended skills relevant to niche
2. Toggle skill switches
3. Click "Começar com essas habilidades"

### 5. Test skill activation

1. Verify: selected skills are `status: 'active'` in `skills` table
2. Verify: `stores.onboarding_completed = true`
3. Verify: redirected to home page

### 6. Test Brand DNA in chat

1. Open chat
2. Ask "escreve uma copy para Instagram"
3. Verify: response reflects the store's tone of voice from Brand DNA

## Verification Checklist

- [ ] Nuvemshop OAuth flow works end-to-end
- [ ] Products sync from real store
- [ ] Brand DNA generated by LLM with real data
- [ ] Analyzing screen shows real progress (not mock timers)
- [ ] Brand DNA page shows real store data
- [ ] Skills recommended based on niche
- [ ] Skill activation persists to DB
- [ ] `onboarding_completed` set to true
- [ ] Brand DNA included in chat system prompt
- [ ] Error handling: retry on sync failure
- [ ] Error handling: partial Brand DNA on LLM failure
- [ ] Redirect: /onboarding → home if already completed
