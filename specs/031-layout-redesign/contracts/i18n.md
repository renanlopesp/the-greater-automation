# Contract: Internationalization (i18n)

## LanguageContext

**Location**: `src/contexts/language-context.tsx`
**Type**: Client component (`"use client"`)

### Provider

```typescript
interface LanguageContextValue {
  language: Language
  setLanguage: (lang: Language) => void
  t: (key: string) => string // Translation function
}

type Language = 'en' | 'pt-BR'
```

### Usage

```typescript
// In any client component
const { language, setLanguage, t } = useLanguage()

// Get translation
<h1>{t("home.greeting")}</h1>

// Switch language
<button onClick={() => setLanguage("pt-BR")}>PT-BR</button>
```

### Storage

- **Key**: `app_language` in localStorage
- **Default**: `"pt-BR"` (primary market is Brazil)
- **Fallback**: If a key is missing in current language, return the English value. If English is also missing, return the key itself.
